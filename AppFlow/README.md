Welcome to the Mindstix iOS Accelerator project! This template provides a solid foundation for iOS app development, featuring reusable architectures, effortless integration, and time-efficient development practices.

## Getting Started

To get started with the iOS application, follow these steps:

1. **Clone the Project:**
   - Clone the project repository from the GitHub repository:
     ```
     git clone [repository_url]
     ```

2. **Build and Launch the Application:**
   - Open the project in Xcode (Xcode 15 or higher required).
   - Select a simulator or a connected iOS device as the build target.
   - Build and run the application by clicking the "Build and Run" button or pressing `Cmd + R`.

3. **Logging In:**
   - Use the following default credentials to log in:
     - Username: test.baseline@mindtix.com
     - Password: Password123
     - These default credentials are retrieved from Firebase as key-value pairs.
     - If you wish to update the default credentials, you can do so by modifying the values stored in Firebase.

4. **Exploring the Application:**
   - After logging in, explore the features and functionalities of the application.
   - Familiarize yourself with the architecture, navigation components, and common utilities provided by the accelerator.

## Contributing

We welcome contributions from the community to enhance the Mindstix iOS Accelerator project. Here's how you can contribute:

1. **Fork the Repository:**
   - Fork the project repository to your GitHub account.

2. **Make Changes:**
   - Make changes, improvements, or fixes in your forked repository.

3. **Submit a Pull Request:**
   - Once you're satisfied with your changes, submit a pull request (PR) to the main repository.
   - Provide a clear description of the changes and the problem they address.

4. **Code Reviews:**
   - Your PR will undergo code review by project maintainers.
   - Address any feedback or suggestions provided during the review process.

5. **Merge and Deploy:**
   - Upon approval, your changes will be merged into the main repository and deployed as part of the project.
